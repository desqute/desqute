# Портфолио Desqute

Одностраничный сайт-портфолио Desqute. Чистый HTML, CSS и JavaScript — без сборки,
зависимостей и установки. Достаточно открыть `index.html` в браузере.

Настоящее имя на сайте не используется: везде указан псевдоним **Desqute**
(в заголовке, hero-блоке, логотипе, аватаре и подвале).

## Структура

```
index.html    весь текст и разметка сайта
styles.css    оформление: цвета, шрифты, сетка, адаптивность
script.js     тема, мобильное меню, появление блоков
.nojekyll     отключает обработку Jekyll на GitHub Pages
```

## Что заменить в первую очередь

Все места, которые нужно отредактировать, помечены в `index.html` комментариями.

1. **Псевдоним и заголовок** — тег `<title>`, `meta name="description"`, `og:`-теги и текст в hero-блоке.
2. **Буква логотипа** — `logo-mark` (`D`), `avatar` и фавиконка в `<head>`.
3. **О себе** — блок `#about`: абзацы и список `facts`.
4. **Проекты** — три карточки в `#projects`: название, описание, теги и ссылки
   (`href="#"` замените на реальные адреса).
5. **Навыки** — списки `chips` в `#skills`.
6. **Контакты** — e-mail в `mailto:`, ник в Telegram и GitHub в `#contact`.
7. **Подвал** — псевдоним в `<footer>`.

Цвета меняются в одном месте — в переменных `:root` и `html[data-theme="light"]`
в начале `styles.css`. Например, акцентный цвет: `--accent` и `--accent-2`.

## Локальный просмотр

Просто откройте `index.html` двойным щелчком. Если нужен локальный сервер
(например, для проверки путей), подойдёт любой из вариантов:

```powershell
# Python
python -m http.server 8000

# Node.js
npx serve .
```

После этого сайт доступен по адресу http://localhost:8000

## Публикация на GitHub Pages

### Вариант 1. Сайт-визитка по адресу `username.github.io`

1. Создайте на GitHub репозиторий с именем `<ваш-ник>.github.io`.
2. Загрузите в него файлы из этой папки (через веб-интерфейс GitHub или через Git).
3. Через минуту сайт откроется по адресу `https://<ваш-ник>.github.io`.

### Вариант 2. Отдельный репозиторий (например, `portfolio`)

1. Создайте репозиторий `portfolio` и загрузите файлы.
2. Откройте **Settings → Pages**.
3. В разделе **Build and deployment** выберите **Source: Deploy from a branch**,
   ветку `main` и папку `/ (root)`. Нажмите **Save**.
4. Через 1–2 минуты сайт будет доступен по адресу
   `https://<ваш-ник>.github.io/portfolio/`.

### Загрузка через Git

```powershell
git init
git add .
git commit -m "Первый вариант портфолио"
git branch -M main
git remote add origin https://github.com/<ваш-ник>/<репозиторий>.git
git push -u origin main
```

Если Git ещё не установлен, скачайте его с https://git-scm.com/download/win
или загрузите файлы на GitHub вручную: **Add file → Upload files**.

## Полезно знать

- Сайт полностью статический: GitHub Pages хостит его бесплатно.
- `vladik.html` в папке — отдельная открытка, к портфолио она не относится.
  Файл добавлен в `.gitignore`, поэтому при загрузке через Git не попадёт в репозиторий.
  Если открытка всё-таки нужна на сайте, уберите её имя из `.gitignore`.
- Тёмная и светлая темы переключаются кнопкой в шапке; выбор запоминается в браузере.
